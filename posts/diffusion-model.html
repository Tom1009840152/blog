原理深度科普

扩散模型是怎么
"画画"的？

从一张纯噪声开始，一步步"擦去"随机，还原出一幅精美图像——扩散模型用物理学中的热扩散方程，重新定义了图像生成的方式。

2026-05-27 阅读约 8 分钟 扩散模型 · DDPM · U-Net · Stable Diffusion

如果你用过 Midjourney、Stable Diffusion 或 DALL·E，你就体验过扩散模型的力量。输入一段文字描述，几秒钟后一幅精美图像跃然屏上——但这背后究竟发生了什么？这个问题的答案，比你想象的更优雅，也更有趣。

本文将用直觉化的方式，带你从头理解扩散模型的完整工作原理：它为什么从"加噪"出发？神经网络在其中扮演什么角色？文字描述又是如何"指挥"图像生成的？

核心直觉

一个反直觉的出发点：先"毁掉"图像

扩散模型的灵感来自物理学中的热扩散现象：一滴墨水滴入水中，会慢慢扩散直到均匀分布，这个过程不可逆——你无法把均匀的墨水自发地重新聚成一滴。

扩散模型借用了这个物理过程，但聪明地反过来使用：先学会"毁掉"图像，再学会"恢复"图像。

扩散模型的两个阶段

→ 前向过程（训练时）

不断向原图添加高斯噪声，经过约 1000 步，将任意图像变成一张纯随机噪声。这一过程完全由数学公式控制，无需学习，是固定的。

清晰图像 → 模糊图像 → 噪声图像

← 逆向过程（推理时）

从一张纯噪声出发，每次预测并去除一点点噪声，经过约 1000 步，还原出清晰图像。这一过程由神经网络完成，需要学习。

纯噪声 → 模糊轮廓 → 清晰图像

关键洞察：前向过程（加噪）是确定的数学操作，任何图像都可以确定性地变成噪声。逆向过程（去噪）才是模型需要学习的核心——它本质上是在学习"这片噪声里藏着什么"。

数学基础

高斯噪声与马尔可夫链：加噪的数学

前向过程的数学非常简洁：每一步只需在图像上叠加一点点高斯噪声（即正态分布的随机数），并同时将原始图像信号稍微"压暗"。

xt = √(1−βt) · xt−1 + √βt · ε，其中 ε ~ 𝒩(0, I)
前向加噪公式：xt 是第 t 步的含噪图像，βt 是噪声强度，ε 是随机高斯噪声

这个公式形成了一条马尔可夫链——每一步的结果只依赖上一步，与更早的历史无关。这个性质带来了一个极其方便的推论：可以直接一步跳跃到任意时刻 t，无需逐步计算：

xt = √ᾱt · x0 + √(1−ᾱt) · ε，其中 ᾱt = ∏s=1t(1−βs)
重参数化公式：可直接从原图 x0 一步生成第 t 步的含噪版本，大幅提升训练效率

这个性质在训练时极为关键：无需每次从头运行 1000 步前向过程，可以随机采样一个时间步 t，直接生成对应的含噪图像用于训练，训练效率因此大幅提升。

噪声调度（Noise Schedule）：βt 如何变化
📈

线性调度（Linear Schedule）

βt 从小到大线性增长。最早被 DDPM 采用，简单有效，但在低信噪比区域（t 接近 1000）会过早完全破坏图像结构。

📉

余弦调度（Cosine Schedule）

ᾱt 按余弦曲线平滑下降，改善了线性调度的缺陷。OpenAI 在 Improved DDPM 中提出，现为主流选择，图像质量更好。

神经网络

U-Net：学会"看见"噪声的神经网络

逆向去噪过程的核心是一个神经网络：给它一张含噪图像和当前时间步 t，让它预测图像中包含的噪声是什么，然后从图像中"减去"这些噪声，图像就会更清晰一点。

这个神经网络采用的主流架构是 U-Net——一种最初为医学图像分割设计的编码器-解码器结构，因其在保留空间细节方面的卓越表现，被扩散模型领域广泛采用。

U-Net 架构示意（扩散模型版）
含噪图像 xt+ 时间步 t 编码
→
下采样块 ×4提取高层特征
→
瓶颈层Self-Attention
→
上采样块 ×4+ 跳跃连接
→
预测噪声 εθ与输入同尺寸

跳跃连接（Skip Connection）是 U-Net 的精髓：编码器每层的特征图直接拼接到解码器对应层，确保细节信息不在深层压缩中丢失，这对图像重建至关重要。

时间步 t 通过 Sinusoidal 位置编码（与 Transformer 中的位置编码思路相同）转换成一个向量，注入 U-Net 的每个残差块，让网络知道"现在处于哪个去噪阶段"——早期去噪（t 大）和晚期精修（t 小）需要截然不同的处理策略。

扩散模型的本质，是在教一个神经网络
区分"这里是信号"还是"这里是噪声"。

文字控制

Classifier-Free Guidance：文字如何"指挥"图像

基础的扩散模型只能生成随机图像，无法响应文字描述。要实现"输入一段话，生成对应图像"，需要引入条件控制机制——最主流的方案叫做 Classifier-Free Guidance（CFG，无分类器引导）。

文字如何融入扩散过程
文本提示词"一只橙色的猫"
→
CLIP 文本编码器→ 文本向量
→
Cross-Attention注入 U-Net
→
引导去噪方向朝文字语义偏移
🎯

Cross-Attention 机制

文本向量作为 Key 和 Value，图像特征作为 Query，每个图像区域都能"查询"哪些文字词汇与自己相关，从而朝正确语义演化。

⚖️

引导强度（CFG Scale）

同时运行有条件和无条件两次去噪，将两者差值乘以引导系数 w（通常 7–12）后叠加。w 越大，图像越贴合文字，但创造性越低。

# CFG 核心公式（伪代码） noise_cond = model(x_t, t, text_embedding) # 有文字条件的噪声预测 noise_uncond = model(x_t, t, null_embedding) # 无条件的噪声预测 # 引导：放大"有条件"和"无条件"之间的差距 noise_guided = noise_uncond + w * (noise_cond - noise_uncond) # w=1 时等同于普通条件生成；w=7~12 时图像更贴近文字 x_prev = denoise(x_t, noise_guided) # 用引导噪声执行去噪一步

训练时，模型随机将约 10% 的样本条件置为空（无条件），强迫模型同时学会"有引导"和"无引导"两种去噪策略，推理时两者结合使用——这就是"无分类器"名称的来源：不需要单独训练一个分类器来提供梯度引导。

训练目标

损失函数：模型在"学什么"

理解了前向加噪和逆向去噪之后，训练目标就变得非常直白：给模型一张含噪图像 xt（由原图 x0 直接一步加噪得到），让模型预测加进去的那个噪声 ε，用预测值和真实值之间的均方误差作为损失。

ℒ = 𝔼x₀, ε, t [ ‖ε − εθ(xt, t)‖² ]
DDPM 简化损失函数：让网络 εθ 预测的噪声尽量接近真实加入的噪声 ε

这个损失函数的优雅之处在于：不需要标注数据——任何一张图像本身就是训练样本，往里面加噪声再让网络去预测，整个过程完全自监督。这也是扩散模型能够用海量无标注图像训练的根本原因。

一个训练步骤的完整流程
采样真实图像 x0来自训练集
→
随机采样时间步 tt ~ U(1, T)
→
随机生成噪声 εε ~ 𝒩(0,I)
→
一步合成 xt重参数化公式
→
U-Net 预测噪声εθ(xt, t)
→
计算 MSE 反向传播更新权重

加速采样

从 1000 步到 20 步：DDIM 与采样加速

原始 DDPM 的一大痛点是推理速度：逆向去噪需要跑完整 1000 步，相当于 1000 次神经网络前向计算，非常慢。DDIM（去噪扩散隐式模型）通过重新设计采样方程，把步数压缩到 20–50 步，同时几乎不损失图像质量。

主流采样器对比
采样器 典型步数 速度 特点
DDPM 1000 步 慢 基准 原始论文方案，随机采样，质量稳定
DDIM 20–50 步 快 50× 提速 确定性采样，支持插值和图像编辑，Stable Diffusion 默认
DPM-Solver++ 15–20 步 极快 75× 提速 高阶 ODE 数值解法，质量与速度最佳平衡，现最常用
LCM / SDXL-Turbo 1–4 步 实时 近似即时 蒸馏技术，牺牲少量质量换取近乎实时的生成速度

DDIM 的核心创新是将原本随机的马尔可夫逆向过程改写为确定性的常微分方程（ODE），使得同一个噪声输入每次生成完全相同的图像——这也使得图像编辑（在噪声空间插值）和风格迁移成为可能。

潜空间扩散

Latent Diffusion：压缩 64 倍的魔法

即便采样步数降到 20 步，在像素空间直接跑扩散仍然很慢——一张 512×512 图像有 78 万个像素，每步都要对这么多数字做计算。Latent Diffusion Model（LDM），也就是 Stable Diffusion 的核心架构，通过在压缩的"潜空间"里做扩散，将计算量降低了约 64 倍。

Latent Diffusion 完整架构
512×512 像素图像3 通道 RGB
→
VAE 编码器压缩 8×
→
64×64 潜变量4 通道
↔
U-Net 扩散在潜空间去噪
→
VAE 解码器还原 8×
→
512×512 生成图像高质量输出

VAE（变分自编码器）负责像素空间与潜空间之间的双向转换，且仅需训练一次，可以复用于所有扩散过程。U-Net 只在 64×64 的潜空间工作，计算量仅为像素空间的 1/64，但生成质量几乎完全保留。

这里的 VAE 与前文 GPT Image 2 使用的 VQ-VAE 不同：LDM 的 VAE 编码到的是连续潜空间，没有离散量化步骤，因此不会引入量化误差，图像过渡依然丝滑——这正是扩散模型在"画面丝滑度"上优于自回归模型的根本原因。

模型谱系

从 DDPM 到 Flux：扩散模型的发展脉络

扩散模型重要里程碑（2020–2025）

2020

DDPM（Ho et al., NeurIPS）

奠基之作，首次系统验证扩散模型在图像生成上的优越性，建立了加噪/去噪的标准框架。

2021

DDIM · Improved DDPM · DALL·E 1

DDIM 将采样步数降至 50 步；Improved DDPM 引入余弦调度；OpenAI 发布第一代 DALL·E 验证文图生成可行性。

2022

LDM / Stable Diffusion · DALL·E 2 · Imagen

LDM 将扩散迁移至潜空间，催生了 Stable Diffusion 开源生态；DALL·E 2 和 Imagen 将文字引导质量推向新高度。

2023

SDXL · Midjourney V5/6 · ControlNet

SDXL 引入双 U-Net 提升分辨率；ControlNet 实现骨骼、边缘等精确结构控制；Midjourney 艺术风格大幅突破。

2024–2025

Flux · SD3 · Sora · 视频扩散全面爆发

Flux 用 DiT（Diffusion Transformer）替代 U-Net，成新一代主流；Sora 将扩散扩展至视频时序建模，开启多模态扩散新纪元。

优劣与边界

扩散模型的优势、缺陷与未来边界

没有完美的架构，扩散模型同样有其固有局限。理解这些边界，才能在实际使用中扬长避短。

扩散模型的核心优劣势
✅

连续空间，天然丝滑

在像素或连续潜空间工作，颜色过渡无需量化，纹理细节和光影渐变自然流畅，是目前最擅长高质量图像生成的架构。

✅

训练稳定，无模式崩塌

相比 GAN 的对抗训练，扩散模型训练过程稳定，不存在 GAN 常见的模式崩塌（mode collapse）问题，覆盖更多样化的图像分布。

✅

可控性强，生态丰富

ControlNet、LoRA、IP-Adapter 等插件生态极为丰富，可通过姿势、深度图、边缘等多种信号精确控制生成结果。

❌

文字渲染是硬伤

在连续空间生成文字字母，模型没有"字符"概念，字母常融化变形。这是扩散模型与自回归模型最显著的差距所在。

❌

指令理解不如语言模型

复杂逻辑关系（如"左边一只猫，右边一条狗，中间是一棵树"）执行准确率较低，在精确空间布局方面明显弱于自回归方案。

❌

推理速度相对较慢

即便有 DDIM 加速，仍需 20+ 步迭代，延迟高于 GAN 的单步生成。实时应用（如视频流）仍面临挑战，虽已有蒸馏方案缓解。

核心结论：扩散模型是目前图像质量天花板最高的生成架构，其连续空间工作方式使画面天然丝滑，但文字渲染和精确指令执行是其结构性弱点。随着 DiT 架构和连续自回归技术的交叉融合，两类方案的边界正在逐渐模糊——未来的图像生成模型很可能是两者的有机结合。
