GPT Image 2 使用教程
从一句想法到可交付视觉

会“描述画面”只是起点。真正稳定的 Image 2 工作流，是先定义交付物，再拆清布局、文字与不可变项，最后用小步迭代把结果收紧。

2026-08-21 图片模型教程 阅读约 15 分钟 ChatGPT · 图片生成 · 图片编辑

OpenAI 在 2026 年 4 月发布 ChatGPT Images 2.0。在 API 中，对应模型名是 gpt-image-2：它接受文字和图片输入，可以生成新图，也可以继续编辑已有图片。

根据 OpenAI 官方提示词指南，这一代的重点并不只是“画得更像”，还包括图片内文字、复杂信息图、多面板构图、参考图保真、风格迁移和透明背景资产。下面先讲普通用户怎样在 ChatGPT 里使用，再给需要批量生产的读者补充 API 参数。

01 · 认识 Image 2

它真正提升的，是对“设计任务”的理解

✦
生成与编辑

从文字生成新图，也能基于一张或多张参考图继续修改。

字
图片内文字

更适合海报、包装、界面与信息图中的清晰文字排版。

▦
复杂构图

可以处理信息图、图解、多格漫画和具有层级的版式。

◎
参考图保真

编辑时更容易保留身份、材质、标签和关键视觉特征。

名称容易混淆：ChatGPT Images 2.0 是面向用户的图片体验，gpt-image-2 是开发者在 API 中调用的模型名。本文说的“Image 2”同时覆盖这两种使用方式。

02 · 使用入口

ChatGPT 与 API，先选适合自己的入口

ChatGPT 对话NO CODE

像与设计师沟通一样提出需求、上传参考图、查看结果，再用自然语言逐轮修改。适合单张创作、灵感探索和需要频繁判断的任务。

适合：海报、封面、社媒图、照片修改、概念设计
gpt-image-2 APIAUTOMATION

通过代码固定模型、尺寸、质量、格式与透明背景，适合把模板接入产品，或自动生成一批规格一致的资产。

适合：电商素材、批量变体、内容流水线、应用内生图

第一次用，建议从 ChatGPT 开始。先确认你能稳定写出一张满意的图，再把已经验证过的提示词和参数迁移到 API。这样能把“创意没想清楚”和“代码参数有问题”分开处理。

03 · 第一次生成

别急着堆形容词，先完成一轮可控闭环

先写清交付物

告诉 ChatGPT 你要的是海报、封面、产品图还是信息图，并给出投放位置。交付物会直接影响构图、留白和文字密度。

确定画幅与构图

写明横版、竖版或方图，以及主体位置、文字区、视觉动线和需要保留的安全边距。不要只写“高级感”。

补全主体、环境与风格

描述人物或产品、动作、场景、光线、材质、色彩和媒介。风格最好拆成可观察特征，而不是只给一个抽象标签。

逐字给出画面文案

需要图片内文字时，把最终文案放进引号，写明只出现一次、不得增删字符，并指定位置、字号层级和字体气质。

添加约束与禁止项

列出必须保留和不能出现的内容：不要水印、不要额外文案、不要改变商标、不要裁掉产品等。约束要具体可检查。

只改一个核心问题

第一版出来后，优先修最大问题。每轮只改布局、文字、颜色或某个对象中的一项，并重复“其他内容保持不变”。

04 · 提示词公式

把提示词写成一份迷你设计 Brief

01交付物
02主体场景
03构图布局
04风格光线
05精确文字
06约束条件
【交付物】 为一家城市咖啡馆制作 4:5 竖版开业海报，用于社交媒体。 【主体与场景】 一杯草莓抹茶拿铁放在深色木桌上，能看见真实的抹茶、牛奶与草莓分层；背景是雨后的街角店面。 【构图】 饮品位于画面右下三分之一；左上留出标题区；品牌名在底部居中；层级清晰，四周保留安全边距。 【视觉风格】 现代日系编辑设计，米白、抹茶绿与草莓红；柔和侧光，纸张颗粒，真实商业摄影与克制排版。 【画面文字｜逐字照抄】 主标题：“春日新店开业” 副标题：“本周六 · 城南路 18 号” 品牌名：“MOSS COFFEE” 【约束】 所有文字只出现一次，不得增删字符；不要水印，不要额外标语，不要虚构商标；饮品杯型与分层必须自然可信。

好的提示词不一定长，但要让人能够验收。把“时尚、震撼、高级”换成具体的布局、光线、材质和颜色；把“文字准确”换成引号中的最终文案与不得增删字符。

05 · 图片内文字

想让字更稳，文案和版式要一起写

OpenAI 官方指南建议：将准确文案放进引号，明确要求逐字呈现、不添加额外字符，并描述文字的位置和字体风格。如果首轮仍有错字，保持文案不变，小幅调整文字密度或布局后再生成。

01
锁定精确文案

先在外部完成校对，再复制进引号。不要让模型替你临场改写主标题。

02
说明层级与位置

分别写主标题、副标题、说明文字和品牌名，并指定对齐、大小与所在区域。

03
减少一次性密度

文字越多，校对成本越高。先生成核心文案，长段说明保留给后期排版工具。

图片模型的文字能力已经显著增强，但高风险信息仍要人工核对。价格、日期、地址、产品参数、法律说明和数据图表不能只凭“看起来像是对的”。

06 · 图片编辑

编辑最稳的写法：改什么，以及什么绝对不动

编辑任务最常见的失败不是“没改”，而是改对一处、漂掉三处。官方指南反复强调：把变化项与不可变项分开写，并在每轮迭代时重新声明不可变项。

允许改变
  • 只把白天改成冬日晚景
  • 增加自然降雪与地面湿润反光
  • 让环境光变冷，窗口灯光变暖
→
必须保持
  • 人物身份、表情、姿势和衣服不变
  • 相机角度、构图与物体位置不变
  • 海报文字、品牌标识与比例不变
【编辑任务】 把这张街景改成冬日晚景，增加自然降雪、湿润路面反光和暖色窗口灯光。 【必须保持】 不要改变人物的脸、发型、表情、姿势与服装；不要改变相机角度、画面裁切、建筑结构和物体位置；图片中的全部文字与品牌标识逐字保持不变；不要添加新人物或新文字。 只修改天气、时间与环境光，其他内容保持不变。

物体移除也遵循同一原则：“移除右手里的花，其他内容不要改变”通常比一大段风格描述更有效。换装、产品合成和参考图迁移时，则要额外锁定人物身份、产品几何、标签文字、光向和阴影。

07 · 实用场景

这些任务最能发挥 Image 2 的优势

📊
信息图与图解

先给出信息层级与准确数据，再定义标题、标签、箭头和配色；生成后逐项核对事实。

🪧
海报与社媒图

把文案、布局、画幅和视觉风格放在同一份 Brief 中，适合快速探索多种设计方向。

◈
品牌视觉提案

围绕同一品牌锚点生成标志应用、包装、物料和场景图，但最终规范仍需设计师统一。

▤
UI 与应用概念

用明确的信息架构、组件类型与状态说明生成概念稿，适合沟通方向，不代替可编辑设计文件。

🎬
分镜与多格叙事

先锁定角色设定，再逐格写动作、景别和对白；每次迭代重复人物不可变特征。

✂️
产品抠图与合成

要求保留产品几何和标签，输出干净轮廓；API 可直接请求透明 PNG 或 WebP。

把 Image 2 当作“会持续对话的视觉协作者”，而不是一次性抽卡工具：先确定方向，再锁定不变项，最后分轮修文字、布局和细节，通常比反复重写整段提示词更稳定。

08 · API 进阶

需要自动化时，再控制尺寸、质量与透明背景

官方模型页把 gpt-image-2 定义为当前用于高质量图片生成与编辑的模型。官方提示词指南还给出了灵活尺寸与透明背景的规则；下表适合做开发时的快速核对。

gpt-image-2 常用参数速查
质量low / medium / high低质量适合快速预览和批量探索；对外素材通常从 medium 验证，高精度需求再比较 high。
尺寸灵活分辨率两边必须是 16 的倍数，长短边比例不超过 3:1；官方建议把 2560×1440 视为较可靠的 2K 上界。
透明背景background: transparent当前为预览能力；输出格式使用 PNG 或 WebP，JPEG 不支持透明通道。
常用尺寸1024² / 1024×1536 / 1536×1024分别适合方图、竖图和横图；最终仍应按展示容器与裁切方式选择。
输入text + image既可纯文字生成，也可带图片做编辑、合成、风格迁移与身份敏感修改。
from openai import OpenAI client = OpenAI() result = client.images.generate( model="gpt-image-2", prompt="一枚极简珐琅胸针，孤立主体，纯透明背景，不要阴影，不要文字", size="1024x1024", quality="medium", background="transparent", output_format="png", )

上面的代码只展示参数组合。实际项目还要按官方最新指南处理返回结果、鉴权、异常与成本；价格和账户限额会变化，部署前以官方模型页和控制台为准。

09 · 稳定出图

常见问题，不要靠“再抽一次”解决

构图不听话
把位置写成可观察的关系：主体在右下三分之一、标题左对齐、上方留 20% 空间。减少同一主体上的冲突指令。
图片文字有错
将最终文案逐字放进引号，要求只出现一次且不得增删；减少字数，分清标题层级，下一轮只修文字。
编辑后人物变了
重复锁定脸、发型、肤色、表情、姿势和体型；明确只允许改变的区域，一轮只做一个修改。
产品标签被重画
要求逐字保留标签与品牌标识，同时锁定产品几何、材质和相机角度；高风险商标仍应人工复核。
风格很“AI”
删掉空泛词，改写为具体媒介、镜头、光源、色温、材质、颗粒和印刷工艺；降低一次提示中的风格数量。
越改越漂
回到最近满意版本，从它继续编辑；列出“允许改变 / 必须保持”两栏，并在每一轮重复不可变项。

点击生成前，最后检查

✓已经写明交付物、使用场景和画幅，而不是只描述画面气氛。
✓主体、构图、光线、材质与颜色都能被直接观察和验收。
✓所有画面文字都经过校对，并放在引号中逐字给出。
✓编辑任务已经分开写清“允许改变”和“必须保持”。
✓一轮只解决一个核心问题，避免同时改角色、布局、风格和文案。
✓地址、价格、日期、数据、商标和法律文字会在发布前人工复核。
✓API 项目已按最新官方文档核对尺寸、格式、质量、价格与账户限额。
