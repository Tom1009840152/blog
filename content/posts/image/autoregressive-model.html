原理深度科普

自回归模型是怎么
"写出"图像的？

把一张图像拆成一串 Token，像写文章一样一个字一个字地"预测"下一个——自回归模型用语言模型的逻辑，重新定义了图像的生成方式。

2026-05-27 阅读约 9 分钟 自回归模型 · VQ-VAE · Transformer · GPT-4o

如果你用过 image2，或者GPT-4o 的图像生成，又或者听说过 LlamaGen、VQGAN，你其实已经接触过自回归图像模型的产物。它的生成方式和扩散模型截然不同——不是从噪声里"擦出"图像，而是像在写一篇文章：一个 Token 一个 Token 地"写"出整张图。

这个思路听起来朴素，背后却藏着精妙的设计：图像本质上是二维的连续像素，要让语言模型的"下一词预测"逻辑能用于图像，需要回答三个核心问题——如何把图像变成 Token 序列？如何建模 Token 之间的依赖？如何用文字来"指挥"生成？本文将带你一一拆解。

核心直觉

一个来自语言模型的类比：图像就是"文章"

语言模型的核心任务是预测下一个词：给定"今天天气很"，模型预测下一个词是"好"的概率比"坏"高。自回归模型把同样的逻辑搬到了图像上：把图像的每一个像素块（Token）看作一个"词"，从左到右、从上到下依次预测。

关键洞察：自回归生成是严格因果的——每个 Token 只依赖它左侧（和上方）的 Token，绝不能看到还未生成的内容。这种"单向性"既是设计约束，也是它天然支持统一文图模型的根本原因。

数学基础

链式法则：把图像概率分解成 Token 序列

自回归模型的数学基础是概率论中经典的链式法则（Chain Rule）：一张图像的联合概率，可以被分解为每个 Token 在其前驱条件下的条件概率之积。

p(x1, x2, …, xN) = ∏i=1N p(xi | x1, …, xi−1)
图像的联合概率被分解为 N 个条件概率之积，每个条件概率只依赖前驱 Token

这个分解方式有一个极其重要的含义：只要能精确建模每一个条件概率，就能精确建模整个图像的分布。神经网络（特别是 Transformer）在这件事上表现出色，因为它能通过注意力机制捕捉任意长程依赖。

与扩散模型的核心建模差异
🌊 扩散模型

在连续空间建模——学习从噪声分布到图像分布的渐进去噪过程，每一步都在全局像素空间操作，建模整张图的分布变换。

📝 自回归模型

在离散 Token 空间建模——学习序列中每个位置的条件分布，每一步只预测一个 Token，积累到完整序列即为完整图像。

图像离散化

VQ-VAE：把连续像素"翻译"成离散 Token

语言模型能预测下一个词，因为词汇表是有限的（比如 5 万个词）。但像素值有无穷多种可能——如果直接对每个像素做 softmax，词汇表大小将达到 256³ ≈ 1600 万，完全不现实。

解决方案是 VQ-VAE（向量量化变分自编码器）：先用一个编码器把图像压缩成低分辨率的特征图，再用一个码本（Codebook）把每个特征向量"量化"到最近的离散编码，从而把图像变成一串整数索引序列。

VQ-VAE 图像离散化流程
256×256 像素图像3 通道 RGB
→
CNN 编码器下采样 16×
→
16×16 特征图每格一个向量
→
向量量化查最近码本项
→
256 个整数索引词汇表大小 8192

码本（Codebook）是一个大小为 K×D 的可学习矩阵（例如 K=8192 个条目，每个 D=256 维）。量化操作将每个连续向量替换为码本中与其欧式距离最近的条目的索引，从而将图像变成长度为 16×16=256 的整数序列。

VQ-VAE 的训练目标是让解码器能从这串索引无损地还原出原始图像。一旦训练完成，编码器和解码器就"冻结"了——后续自回归模型只需要学习这 256 个整数索引构成的序列如何生成，不再直接面对像素。

VQ-VAE vs 扩散模型 VAE 的关键区别
维度 VQ-VAE（自回归用） 连续 VAE（扩散模型用）
潜空间类型 离散整数索引 连续实数向量
量化误差 有，但码本够大可以控制 无，信息保留更完整
下游建模 适合语言模型（softmax 分类） 适合扩散模型（连续去噪）
文字渲染能力 强——字符可对应固定 Token 弱——连续空间难以精确复现字形

Transformer 骨干

GPT 式 Transformer：序列建模的最强引擎

把图像变成 Token 序列之后，自回归图像模型的骨干网络和语言模型用的是同一套架构：仅解码器（Decoder-only）的 Transformer，也就是 GPT 的结构。

核心机制是因果自注意力（Causal Self-Attention）：通过在注意力矩阵上施加下三角掩码（Causal Mask），确保位置 i 的 Token 只能看到位置 1 到 i 的 Token，永远无法看到未来。这样在训练时，所有位置的预测可以并行计算；在推理时，则逐个生成每个 Token。

Decoder-only Transformer 处理图像 Token 序列
Token 序列[tok₁, tok₂ … tokₙ]
→
词嵌入 + 位置编码2D 位置感知
→
因果自注意力层 × LCausal Mask 屏蔽未来
→
线性 + Softmax输出词汇表概率
→
采样下一个 Tokenargmax / top-k / top-p

与语言模型的最大区别在于位置编码：图像 Token 是二维排列的（行 × 列），需要引入 2D 感知的位置编码（如 2D RoPE 或行列分离编码），而非语言模型的线性位置编码，才能让模型理解空间结构。

由于架构与语言模型完全一致，自回归图像模型天然可以和文本 Token 混合训练——只需把文本 Token 和图像 Token 拼接成同一条序列，就可以在一个模型里同时学会"读文字"和"画图像"，这正是 GPT-4o 等统一多模态模型的技术基础。这条路线的集大成者是 OpenAI 于 2025 年发布的 GPT Image 2——它将超大规模码本与千亿级 Transformer 结合，首次让在图像中无差错书写任意文字成为常规能力，被业界视为当前自回归图像生成的天花板。

自回归模型的终极野心：
用一个模型、一套权重，
同时理解文字、生成图像。

文字控制

Cross-Attention 与条件前缀：文字如何"指挥"图像

让自回归模型响应文字描述，主要有两种方案，各有优劣：

两种文字条件注入方式对比
📎

方案一：条件前缀（Prefix）

将文字 Token 直接拼在图像 Token 序列前面，让因果注意力机制自然地让图像 Token 关注到文字 Token。结构最简单，适合统一模型（如 LlamaGen、GPT-4o）。

🔀

方案二：交叉注意力（Cross-Attention）

保持图像 Token 序列独立，通过额外的 Cross-Attention 层让每个图像 Token 去"查询"文字编码器的输出。与扩散模型的文字注入方式相同，条件信号更独立。

文字 Token"一只橘猫在草地上"
→
文字编码器CLIP / T5
→
文字嵌入序列语义向量
→
拼接 / Cross-Attn注入图像生成流
→
条件化 Token 预测每步都受文字约束

条件前缀方案的优雅之处在于：文字和图像共享同一个注意力空间，模型可以在生成每个图像 Token 时，对任意位置的文字 Token 施加注意力——这让模型能自然地对齐"一只"对应前景主体 Token、"草地"对应背景 Token，实现精细的空间语义对齐。

训练目标

交叉熵损失：最简单也最有效的目标函数

自回归模型的训练目标极为简洁：给定前缀 Token，最大化下一个 Token 的预测概率。损失函数采用标准的交叉熵（Cross-Entropy）：

ℒ = − ∑i=1N log pθ(xi | x1, …, xi−1)
最小化负对数似然：让模型对每个位置的真实 Token 赋予最高概率

这个损失函数有几个非常好的性质：首先，训练完全并行——通过 Causal Mask，所有位置的预测可以一次前向计算完成，无需像推理时那样逐步生成；其次，无需额外标注——只要有图像-文字对，图像 Token 序列本身就是训练目标，天然自监督；最后，文字和图像可以混合训练，用同一个损失函数，同一套权重，模型自然学会两种模态。

一个训练步骤的完整流程
采样图像-文字对来自训练集
→
VQ-VAE 编码图像得到 Token 序列
→
拼接文字前缀[text | img_tokens]
→
Transformer 前向并行预测所有位置
→
交叉熵损失仅对图像位置计算
→
反向传播更新Transformer 权重

训练时仅在图像 Token 位置计算损失（文字位置不参与，因为文字是"已知条件"）；推理时则从 BOS（序列起始符）开始，逐个采样图像 Token，直到生成 EOS（序列结束符）或达到预设长度。

采样策略

温度、Top-k、Top-p：控制生成的"随机性"

每一步推理，Transformer 输出一个长度为 K（码本大小）的概率分布，模型需要从中采样一个 Token。采样策略直接决定生成图像的多样性与质量之间的权衡。

三种主流采样策略
🌡️

Temperature 缩放

将 logits 除以温度 T 后再 softmax。T < 1：概率更集中，图像更清晰但多样性低；T > 1：概率更均匀，多样但可能有噪声。

🔝

Top-k 采样

只保留概率最高的 k 个 Token，其余置零后重新归一化。k 越小生成越保守，k=1 退化为贪心解码（argmax），质量高但完全确定性。

📊

Top-p（核采样）

保留累积概率超过 p（如 0.95）的最小 Token 集合。能动态调整候选数：分布尖锐时候选少，分布平坦时候选多，比 Top-k 更自适应。

# 采样策略核心代码（伪代码） logits = transformer(tokens, text_cond) # 形状 [vocab_size] # 1. Temperature 缩放 logits = logits / temperature # temperature=0.8 更保守 # 2. Top-k 过滤 top_k_indices = argtopk(logits, k=2048) logits[~top_k_indices] = -inf # 3. Top-p 核采样 probs = softmax(logits) sorted_probs, sorted_idx = sort(probs, descending=True) cumprobs = cumsum(sorted_probs) cutoff = sorted_idx[cumprobs > 0.95][0] # 找到截断点 logits[sorted_idx[cutoff:]] = -inf # 4. 采样 next_token = multinomial(softmax(logits)) # 按概率随机采样

实际工程中，三种策略通常组合使用：先做 Top-k 截断，再做 Top-p 过滤，最后用温度调节尖锐度，然后采样。典型设置：T=1.0、k=2048、p=0.95，在质量与多样性之间取得良好平衡。

模型谱系

从 PixelCNN 到 GPT-4o：自回归图像模型的发展脉络

自回归图像模型重要里程碑（2016–2025）

2016

PixelCNN / PixelRNN（van den Oord et al., DeepMind）

自回归图像生成奠基之作，直接在像素空间建模，证明了逐像素预测可以生成合理图像。受限于 CNN 感受野，生成质量和分辨率有限，但开创了思路。

2019

VQ-VAE-2（DeepMind）

引入多尺度 VQ-VAE（粗粒度 + 细粒度码本），配合 PixelSnail 先验，首次在 ImageNet 256×256 上生成媲美 BigGAN 的图像质量，标志着自回归路线进入实用阶段。

2021

DALL·E 1 · VQGAN + CLIP · ImageGPT

OpenAI 的 DALL·E 1 首次实现大规模文图自回归生成；VQGAN 优化了码本训练；ImageGPT 验证了 GPT-2 架构直接生成像素的可行性，但分辨率受限。

2022–2023

PARTI · LlamaGen · RQ-Transformer

Google 的 PARTI（20B 参数）将文图生成质量推向新高；LlamaGen 证明标准 LLaMA 架构可直接用于图像生成；RQ-Transformer 引入残差量化压缩序列长度。

2024

GPT-4o · Janus · Show-o · 统一多模态模型全面爆发

OpenAI GPT-4o 将文字理解与图像生成统一到同一个自回归模型；Janus、Show-o 等统一模型验证了"一个模型处理所有模态"的可行性；自回归路线在文字渲染上的优势被广泛认可。

2025

GPT Image 2（OpenAI）— 当前自回归图像生成天花板

OpenAI 发布 GPT Image 2，在自回归架构基础上将文字渲染、精确指令执行和真实感质量同时推向业界顶峰。采用大规模 VQ-VAE 码本（数万条目）结合超大 Transformer，首次让"在图像中无差错书写任意文字"成为常规能力；同时支持对话式迭代编辑，用户可通过多轮对话精细修改画面细节，是自回归路线规模化扩展的集大成之作。

优劣与边界

自回归模型的优势、缺陷与未来边界

自回归模型与扩散模型是当前图像生成的两条主线，各有其不可替代的优势和结构性缺陷。

自回归图像模型的核心优劣势
✅

文字渲染是天然优势

离散 Token 建模让字母可以对应固定的 Token 模式，模型有清晰的"字符"概念。相比扩散模型在连续空间"画字母"，自回归模型渲染文字更精确可靠。

✅

统一建模，天然多模态

文字和图像 Token 共享同一序列空间和同一套权重，模型可以同时理解、编辑、生成多种模态，是构建通用多模态 AI 助手的最自然架构。

✅

精确指令执行能力强

借助语言模型的强大推理能力，在"精确空间布局"（左边一只猫、右边一条狗）等复杂指令上表现明显优于扩散模型，因为文字理解和图像生成是同一个模型。

✅

可伸缩性（Scalability）极强

与语言模型共享架构，可直接受益于 LLM Scaling Law 的经验积累——加大模型、加大数据，质量稳定提升，参数效率随规模增大而提高。

❌

推理速度是最大瓶颈

生成一张 256×256 的图像需要顺序预测 256 个 Token，每步都要跑一次完整 Transformer 前向计算，无法并行化。在速度上远慢于扩散模型的批量去噪。

❌

图像细节质量略逊

量化误差（VQ-VAE 码本限制）导致高频细节（纹理、毛发、光影）略逊于扩散模型的连续潜空间。码本越大可以缓解，但也增加了序列长度和计算量。

❌

序列过长，上下文窗口压力大

高分辨率图像（1024×1024）经过 VQ-VAE 压缩后仍可能有 4096 个 Token，超出许多模型的上下文窗口，且注意力计算复杂度为 O(N²)，显存压力极大。

❌

错误累积（Error Accumulation）

逐 Token 生成时，早期的预测偏差会影响所有后续 Token——一步错步步错。相比扩散模型每步都在全局优化，自回归的局部贪心预测更容易出现语义偏移。

核心结论：自回归模型是目前文字渲染能力最强、指令执行最精确、多模态统一潜力最大的图像生成架构。其离散 Token 建模方式与大语言模型天然融合，是构建通用多模态助手的首选路径。随着 KV Cache 优化、推测解码（Speculative Decoding）和更大码本的进步，推理速度瓶颈正在被逐步突破——自回归与扩散的融合方案（如 MAR、MAGE）也已出现，两条路线相互借鉴、加速收敛。
