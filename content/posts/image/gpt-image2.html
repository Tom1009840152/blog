核心差异

扩散模型 vs 自回归模型：两种截然不同的"绘画哲学"

理解块状感的来源，首先要理解两种主流图像生成架构的根本区别。扩散模型和自回归模型面对"如何生成图像"这个问题，给出了完全不同的答案。

视觉效果对比示意

✦ 扩散模型（连续空间）

像水彩晕染，在连续的像素空间逐步去噪。颜色过渡自然细腻，没有人为的分割边界，边缘柔和如真实照片。

✦ 自回归模型（离散 Token）

像马赛克拼图，把图像切成离散的"视觉词"逐块生成。块与块之间可能出现不连续的跳变，形成块状感。

根本原因

VQ-VAE：把图像"量化"成词汇的代价

GPT Image 2 采用自回归架构——它把图像视为一个"视觉单词序列"，逐个 token 地生成图像，就像 GPT 逐字生成文本一样。要实现这一点，图像需要先被"量化"成离散的 token，这一步骤由 VQ-VAE（矢量量化变分自编码器）完成。

VQ-VAE 相当于图像版的 Word Embedding——它维护一本包含约 8,192 个"视觉单词"的词典（Codebook），每个图像块都被强制对齐到词典中最接近的那个词。这个"强制对齐"的过程，正是块状感的根源。

VQ-VAE 的工作分三步：① 切块——把输入图像切成若干 8×8 像素的小块；② 编码——将每个小块压缩成一个高维特征向量；③ 量化——在词典里找到与该向量最接近的"视觉词"，强制替换。解码时再把词典中的词还原回像素。

关键问题在第③步：词典里只有 8,192 个词，但世界上的颜色和纹理是无限的。每次"找最近的词"都会引入误差，而且这个误差是永久性的——后续步骤再也拿不回这部分精度。

问题的关键在于：真实世界的图像是连续的，像素值可以是 0 到 255 之间的任意数字，颜色渐变可以无限细腻。但量化之后，这无限的可能性被压缩成仅仅 8,192 个选项。更糟糕的是，相邻两个图像块可能被映射到词典中相距很远的两个词，即使原图两块之间只有极其微妙的过渡，量化后也会出现突变——这就是肉眼看到"块状感"的直接原因。

量化误差如何导致块状感

原图颜色连续过渡，量化后相邻块被迫跳到不同的词典词条，边界突变：

# 原图：颜色连续渐变（理想） 块A: #E8C4A0 → 块B: #E2BB95 → 块C: #DCB28A （细腻过渡） # 量化后：强制对齐词典，相邻块跳到不同词条 块A: #F0C8A8 → 块B: #F0C8A8 → 块C: #C8A070 （突然跳变 ← 块状感来源） # 类比：把 100 种肤色压缩成 3 种，过渡区域必然出现色块边界

三重叠加

块状感来自三重递进效应

上一节说明了 VQ-VAE 量化是块状感的根本来源。但量化只是第一层——自回归架构在此基础上还叠加了另外两个固有问题，三者递进，共同放大了最终肉眼可见的块状感。

三重叠加效应分析

① 量化精度损失（根源）

即上节所述：相邻图块被强制映射到不同词典词条，颜色过渡在编码阶段就已断裂，精度永久损失，是后两层问题的基础。

② 空间结构损失

图像是二维平面，强行展平为一维序列后，空间上紧邻的两个图像块在序列中可能相距很远，模型难以维护跨块的空间一致性。

③ 解码拼接误差

各 token 独立解码后拼合，交界处可能出现肉眼可见的"拼图缝隙"，在颜色渐变剧烈的区域尤为明显。

扩散模型在像素的连续海洋中游泳，
自回归模型在离散的砖块上跳格子。

主动取舍

OpenAI 为何仍然选择自回归？

既然存在如此明显的缺陷，为何 OpenAI 要选择自回归架构？答案是：这是一次经过深思熟虑的主动取舍，用画面的丝滑度，换来了其他维度的突破性优势。

对于 GPT Image 2 的核心应用场景——海报设计、品牌物料、UI 原型、产品示意图——文字渲染的准确性远比画面的丝滑度更重要。传统扩散模型的字母常常融化变形，而自回归架构将准确率提升至 99%。

选择建议：如果需要文字准确、内容可控的实用图像，选 GPT Image 2；如果追求画面丝滑、艺术感强的视觉作品，选 Midjourney 等扩散模型。两者各有最优应用场景，不存在绝对的优劣。

未来展望

块状感会被彻底解决吗？

研究界已经在积极探索多种缓解方案，块状感并非不可攻克的顽疾。

四种缓解路径

扩大词典容量

从 8,192 扩展到 65,536 个视觉词，量化误差显著减小，代价是训练难度和推理延迟同步上升。

缩小 Token 粒度

每个 token 从 8×8 像素缩小到 4×4 像素，块状感减弱，但 token 数量从 1024 增加到 4096，速度更慢。

混合架构后处理

自回归生成粗糙结构，再叠加扩散模型平滑细节。两步结合，各司其职，已有研究验证可行。

连续 Token（根本解法）

放弃离散量化，直接在连续空间做自回归，从根本上消除块状感。技术挑战最大，是研究前沿。

更根本的方向是让自回归模型直接在连续空间工作——一旦突破，将从根本上消除块状感，同时保留自回归架构在文字渲染和指令理解上的所有优势。这是当前学界最活跃的研究方向之一。

核心结论：块状感是自回归模型"把图像当语言"的代价，丝滑是扩散模型"在连续空间工作"的天然优势。这不是谁优谁劣，而是两种设计哲学在不同维度的取舍。随着连续自回归技术的成熟，这一代价有望在未来几年内被消除。
